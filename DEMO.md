# Demo Video Script — Out of Focus (2–3 min)

Film in a desktop browser with the **tab bar visible** (favicon + title). That chrome is the creative differentiator.

## Beats

| Time | Shot | What to show |
|------|------|----------------|
| 0:00–0:20 | Title / hook | Menu: “Out of Focus” + line “the threat lives in your tab bar” |
| 0:20–0:50 | Arena | WASD combat, XP gems, level-up pick |
| 0:50–1:20 | Medusa | “LOOK AWAY” vignette → Ctrl+Tab → survive |
| 1:20–1:50 | Dread | Camera on tab: favicon morph + title whispers / “NOW — return!” |
| 1:50–2:20 | Cash-in | Perfect Return shockwave, then a failed Overstay → Tab Stalker |
| 2:20–2:45 | Close | Squeeze density + “can’t play this on a console” |

## Capture tips

- Use a clean Chrome/Edge window; zoom UI 110% if title text is hard to read
- Do one take where you deliberately overstay so the red favicon + stalker land on camera
- Soft background music optional; SFX not required for MVP
