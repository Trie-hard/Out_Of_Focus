# Out of Focus — itch.io page copy

**Short:** A tab-bar roguelite — Ctrl+Tab to survive.

**Description:**

Out of Focus is a top-down wave survival game where the real boss is your **browser tab**.

Fight geometric hordes. Forage HP and Focus Shards by leaving the tab. Dodge Medusa Gazes by literally looking away. Return in the teal dread window for a Perfect Return shockwave — or overstay and meet the Tab Stalker.

**Unique features**
- Page Visibility API as core combat
- Dynamic favicon + title theater (pupil tracks enemy clusters)
- Sirens that only die when you look away
- Mirrors that echo your last hide duration
- Focus Debt if you never unfocus
- Boss-lite events every ~2 minutes

**Controls:** WASD · auto-fire · Ctrl+Tab / click another tab · H help · M mute

**Platform:** Desktop Chrome / Edge / Firefox recommended (needs real tab focus).

**Tags:** survival, roguelite, experimental, horror-lite, browser

**Instructions (itch):**
WASD to move. Weapons auto-fire. Ctrl+Tab (or click another tab) to forage — but dread rises. (Alt+Tab switches apps, not browser tabs.) Return in the teal favicon / dread-bar window for a Perfect Return. When the game says LOOK AWAY, leave the tab or take massive damage. Title tips marked with ✓ are real safe zones — sprint there after returning.
